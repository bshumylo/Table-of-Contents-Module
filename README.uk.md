# Table of Contents (модуль Joomla!)

[In English](README.md)

Нативний модуль сайту для Joomla! 6, який автоматично будує **зміст статті** із заголовків матеріалу, що зараз переглядається. Список збирається у браузері з уже відрендереного тексту, тому працює з будь-яким редактором, будь-якими контент-плагінами та будь-якою розміткою заголовків — нічого не зберігається й нічого не парситься на сервері.

## Можливості

- Зміст будується на клієнті з власних заголовків статті, тому завжди відповідає тому, що бачить читач.
- Налаштовувані рівні заголовків (`H2`–`H6`) і мінімальна кількість заголовків, нижче якої модуль повністю ховається — разом із обгорткою (chrome).
- Виводиться у тій позиції шаблону, куди призначений, і заповнює її — розміщенням керує звичайна позиція модуля Joomla, а сам блок не має власної ширини, тож однаково лягає в бічну колонку, у колонку конструктора чи у flex-контейнер.
- Опційна нумерація, згортання блоку (за потреби — згорнутий одразу) та плавна прокрутка з налаштовуваним відступом для «липких» шапок сайту.
- Оформлення: колір фону, рамки, тексту й посилань, розмір шрифту, додатковий CSS-клас і поле Custom CSS для конкретного екземпляра модуля.
- Налаштовуваний CSS-селектор тіла статті — для шаблонів із нестандартною розміткою.
- Без зовнішніх залежностей і мережевих запитів — звичайні веб-асети Joomla (DI service provider, module dispatcher, шаблон з можливістю override).
- Переклади `en-GB` та `uk-UA` в комплекті.

## Вимоги

- Joomla! 6.0 або новіша
- PHP 8.3+

## Встановлення

1. Завантажте останній `mod_toc-x.y.z.zip` зі сторінки [Releases](../../releases).
2. В адмінці Joomla перейдіть у **Система → Встановити → Розширення** і завантажте zip.
3. Перейдіть у **Матеріали → Модулі сайту**, створіть модуль **Table of Contents**, призначте йому позицію та пункти меню зі статтями.

Модуль виводиться лише на сторінках матеріалів `com_content`; на решті сторінок він не дає жодного виводу.

## Налаштування

### Основні

| Параметр | Типове значення | Опис |
| --- | --- | --- |
| Заголовок | *(порожньо)* | Заголовок над списком. Порожньо = типовий заголовок. |
| Рівні заголовків | H2, H3, H4 | Які теги заголовків потрапляють у зміст. |
| Мінімум заголовків | 2 | Модуль ховається, якщо у статті менше відповідних заголовків. |
| Нумерований список | Ні | Нумерує пункти замість простих посилань. |
| Згортання | Так | Додає перемикач згортання блоку. |
| Згорнутий одразу | Ні | Стартує згорнутим (лише разом зі *Згортанням*). |
| Плавна прокрутка | Так | Анімований перехід до заголовка. |
| Відступ прокрутки (px) | 20 | Вертикальний відступ при переході — для «липких» шапок. |

### Оформлення

| Параметр | Типове значення | Опис |
| --- | --- | --- |
| Колір фону | *(порожньо)* | Фон блоку; якщо порожньо — фон шаблону. |
| Колір рамки | *(порожньо)* | Рамка блоку; якщо порожньо — нейтральний сірий. |
| Колір тексту | *(порожньо)* | Успадковується від шаблону, якщо порожньо. |
| Колір посилань | *(порожньо)* | Успадковується від шаблону, якщо порожньо. |
| Розмір шрифту | *(порожньо)* | Напр. `14px` чи `0.9rem`; успадковується, якщо порожньо. |
| Додатковий CSS-клас | *(порожньо)* | Додатковий клас на обгортці. |
| Custom CSS | *(порожньо)* | Сирі CSS-декларації лише для цього екземпляра модуля — без селектора і без фігурних дужок. |

### Додатково

| Параметр | Типове значення | Опис |
| --- | --- | --- |
| CSS-селектор тіла статті | `.com-content-article__body, [itemprop='articleBody'], .item-page .article-content, .article-content, .uk-article [property='text']` | Селектор контейнера тексту статті. Змінюйте лише для нестандартних шаблонів. |
| Альтернативний макет | `default` | Стандартний вибір макета модуля Joomla. |

Якщо селектор нічого придатного не знаходить, модуль визначає контейнер статті самостійно: піднімається вгору від першого заголовка, що не належить шапці, підвалу, навігації, бічній панелі чи іншому модулю, і зупиняється на першому предку з достатньою кількістю заголовків. Заголовки сторінки, а не статті (наприклад, блок пов'язаних дописів), до змісту не потрапляють.

### Розміщення й ширина

Зміст виводиться там, куди його поставила Joomla: позицію шаблону обирайте у власному налаштуванні **Позиція** модуля, як і для будь-якого іншого модуля. Блок не має власної ширини — він заповнює позицію, у якій стоїть (`width: 100%` плюс `flex: 1 1 auto` і `min-width: 0`, щоб коректно поводитись у flex- чи grid-контейнері). Тож бічна позиція дає вузьку колонку, а широка — блок на всю ширину. Розміри задавайте позицією, шаблоном або полем **Custom CSS** модуля.

### Конструктори сторінок (YOOtheme Pro)

У макеті конструктора YOOtheme Pro тіло статті не має стабільного CSS-хука, тож заголовки знаходить саме автовизначення. Сам модуль лишається в тій позиції чи елементі конструктора, куди його поставили, а панель-обгортка YOOtheme (`module-<id>`, `uk-panel`) зберігає своє оформлення. Оскільки YOOtheme Pro не виводить позицію `sidebar` на сторінках конструктора, ставте модуль елементом *Module* у потрібну колонку.

### Override шаблону

Розмітку можна перевизначити для свого шаблону, скопіювавши `tmpl/default.php` у:

```
templates/<ваш-шаблон>/html/mod_toc/default.php
```

## Про безпеку

Поле **Custom CSS** свідомо зберігається без фільтрації — CSS не є HTML, і стандартний фільтр рядків Joomla зіпсував би коректні декларації. Значення санітизується при кожному рендері перед виводом: вирізаються вихід із селектора, фігурні дужки, коментарі, at-правила та застарілі вектори «скрипт у CSS». Тож навіть оператор із правами редагування модуля не може вставити розмітку чи скрипт у сторінку.

Маніфест містить `<changelogurl>`, тому номер версії у **Система → Керування → Розширення** є кнопкою, яка відкриває нотатки випуску для встановленої версії. ## Розробка й тестування

- Юніт-тести: `vendor/bin/phpunit -c phpunit.xml.dist` (потрібен vendor-автозавантажувач Joomla; вкажіть `JOOMLA_ROOT` або встановіть `joomla/registry` локально).
- Збірка інсталяційного zip: `bash build/build.sh` (або `powershell -File build/build.ps1` у Windows) — результат у `dist/`.
